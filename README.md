# 核核工具箱 (HeHe Toolbox)

> Windows 桌面效率工具箱 · 100 个工具 · 全部本地运行

![tech](https://img.shields.io/badge/Electron-43-165DFF)

## 快速开始

```bash
npm install        # 首次安装依赖（已配置 npmmirror 镜像）
npx electron .     # 启动应用
```

> 若首次安装后提示 "Electron failed to install correctly"，执行：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node node_modules/electron/install.js`

## 架构

```
main.js            主进程：窗口/托盘/全局热键 + IPC 能力层
                   （文件系统、哈希/加密、进程、网络、系统信息、静态服务器…）
preload.js         contextBridge 安全暴露 API
js/
  api.js           IPC 封装（浏览器演示模式自动降级）
  ui.js            组件库（表格/弹窗/Toast/开关/拖拽区/折线图…）
  registry.js      工具注册表（插件化：新增工具一行注册，自动进导航+搜索）
  app.js           外壳：路由/标签页/收藏/最近使用/设置页
  tools/*.js       按模块分组的工具实现
```

- 配置与数据保存在 `%APPDATA%/hehe-toolbox/hehe-data.json`（收藏、最近使用、剪贴板历史、便签、快捷项、命令收藏），全部本地存储。
- 所有联网功能（公网 IP、翻译、测速）仅在用户主动点击时发起。

## 打包发布

```bash
npm run dist:retry       # 便携版单 exe + 免安装 zip → dist/（推荐）
npm run dist:installer   # NSIS 安装版 → dist/hehe-toolbox-Setup-<版本>.exe
```

- **两种发布形态**：
  - `hehe-toolbox-Portable-<版本>.exe` —— 单文件，双击即用；每次启动要先把 Electron 解压到临时目录，冷启动 6~16 秒。
  - `hehe-toolbox-<版本>-win-x64.zip` —— 免安装目录版，解压一次后每次启动约 1.1 秒，在意启动速度就用它。
- 配置与数据保存在 `%APPDATA%\hehe-toolbox`，与开发版共享，便携版/安装版/开发版数据互通
- **不要用 `npm run dist` 直接构建**：它会往 `dist/` 写中间产物 `win-unpacked`，而本机文件观察器会长期锁住其中的 `app.asar`（EBUSY）。`dist:retry` 会把中间产物放到工作区外的暂存目录，只把最终产物拷回来。
- 重新构建需设置镜像：`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ npm run dist:retry`

## 高危功能开关

有 8 项破坏性能力**默认关闭**，需到「设置 → 高危功能」里逐项开启（开启时会二次确认）：

| 能力 | 影响 |
|---|---|
| 删除文件 | 删除重复文件、空目录、笔记、剪贴板图片等（不进回收站） |
| 垃圾清理 | 清理系统临时文件、浏览器缓存、缩略图缓存 |
| 清空回收站 | 永久清空，不可恢复 |
| 结束进程 | 强制结束任意进程，未保存数据会丢失 |
| 停止系统服务 | 依赖该服务的程序可能异常退出 |
| 关机 / 重启 / 休眠 | 系统电源操作（锁屏与睡眠不受限制） |
| 编辑 Hosts | 写入系统 hosts 并刷新 DNS，影响全机解析 |
| 注册表与右键菜单 | 删除开机自启项、切换 Win11 经典右键菜单 |

这些工具在界面上用**红色卡片**标出，与普通功能区分。主进程侧有硬门禁 —— 即使渲染层被绕过，未开启的能力也无法执行。

## 自动更新与 CI

- **检查更新**：设置页「关于」一键检查。安装版走 electron-updater（NSIS 全量升级）；便携版查询 GitHub Releases 最新版，检测到新版本后内置下载（进度显示），下载完成可点「🚀 重启并替换」自动覆盖程序文件并拉起新版（配置与数据不受影响）；也可手动打开所在目录自行替换。查询带 **ETag 条件请求 + 6 小时本地缓存**，正常使用几乎不消耗 GitHub 匿名限流配额；缓存过期且网络失败时会明确报错并提示已知最新版本。
- **升级安全**：替换前自动把旧版备份为 `.bak`，并生成 `rollback.ps1` 回滚脚本 —— 新版本若无法启动，运行脚本即可退回。替换失败会自动还原备份。升级成功后自动清理残留下载包（每次升级不再累积 90MB+）。
- **CI**：push / PR 自动做全量语法检查 + 版本号规则校验 + 工具注册数（≥90）守卫 + 单元测试 + **冒烟测试**（真的启动 Electron 渲染全部工具页）；推送 `v*` 标签自动在 Windows 构建便携版与 zip 并创建**草稿 Release**（人工核对后发布）。
- 托盘右键菜单可直达常用工具：截图标注、贴剪贴板图片、记事、OCR 剪贴板图片等。

## 存储卫生

- 剪贴板历史的图片条目会**连带删除对应 PNG 文件**（清空、单条删除、超出 100 条上限淘汰时都会清理），不会再无限堆积。
- 启动时自动清扫 24 小时前的截图临时文件与孤儿录制分段目录；并回收 `clip-img` 中已无引用的图片。
- 录制过程中途崩溃留下的分段目录，下次启动会被清理。
