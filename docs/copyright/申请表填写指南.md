# 软著申请表逐字段填写指南

> 对照这份表,在中国版权保护中心登记系统里一格一格填。
> **加粗**的是必须用你本人真实信息、我不能代填的字段。

---

## 一、申请基本信息

| 系统字段 | 填什么 | 说明 |
|---|---|---|
| 申请类型 | 计算机软件著作权登记 | 默认选项 |
| 登记方式 | 一般登记 | 不要选"加急"(要额外付费) |
| 是否为职务作品 | **否** | 个人独立开发,不归属公司 |
| 权利取得方式 | 原始取得 | 自己写的 |
| 权利范围 | 全部权利 | 复制、发行、出租、信息网络传播等全套 |

## 二、软件基本信息

| 系统字段 | 填什么 | 依据 |
|---|---|---|
| 软件全称 | **核核工具箱软件** | 全站文档统一用这个名 |
| 软件简称 | 核核工具箱 | 可选填 |
| 版本号 | **V1.0** | ⚠️ **不要填 0.9.6** |
| 软件分类 | 应用软件 → 系统工具软件 | 下拉两级 |
| 开发完成日期 | **2026 年 11 月 25 日** | 与版本 tag 日期一致 |
| 首次发表日期 | **2026 年 11 月 25 日** | GitHub 发布即发表 |
| 发表状态 | 已发表 | 有公开 Release |
| 开发方式 | **独立开发** | ⚠️ 别选"合作"/"委托",否则要交合同 |
| 源程序量 | **49,001 行** | 已实测,不含第三方依赖 |
| 页数 | 60 页 | 前 30 + 后 30 |

### 版本号为什么必须写 V1.0

系统对版本号有格式校验,**只认 `V数字.数字` 格式**。`0.9.6` 这种开发版本号:
- 会被提示"版本号格式不规范"
- 或者被审成"预发布版本",要求说明状态

写 **V1.0** 意味着"首个正式发布版本",后续 1.1 / 1.2 属于升级,不需要重新登记。

## 三、开发者 / 著作权人信息(个人申请)

> ⚠️ **这一节必须全部填你本人的真实信息**,一个字段错就会被要求补正。

| 系统字段 | 填什么 | 注意 |
|---|---|---|
| 著作权人类型 | **自然人** | 选"个人"而不是"法人" |
| **姓名** | **你的身份证上的姓名** | ⚠️ 不能填 `hehe`、不能填网名、不能填拼音 |
| **证件类型** | 居民身份证 | 默认 |
| **证件号码** | **18 位身份证号** | 最后一位可能是 X,大写 |
| **国籍** | 中国 | |
| **证件地址** | **身份证上的住址**(全文照抄) | 精确到门牌号 |
| **联系地址** | 你现在能收到信件的地址 | 可以是工作地/租房地址 |
| **邮政编码** | 6 位 | 与联系地址对应 |
| **手机号** | 你现在用的号码 | 会收验证码 |
| **电子邮箱** | 常用邮箱 | 受理通知发这里 |
| 是否为多人合作 | 否 | 单人开发选否 |

### 姓名必须与身份证完全一致

这几种写法都会被驳回:

| 错误写法 | 问题 |
|---|---|
| `hehe` | 网名,不是法定姓名 |
| `He He` | 拼音/英文,不是身份证姓名 |
| `核核` | 昵称 |
| 姓名里有空格 | 多打了空格 |
| 生僻字用拼音代替 | 必须用身份证上的字 |

### 证件地址怎么填

**照抄身份证背面的住址**,例如:

```
浙江省杭州市西湖区文三路 138 号 5 幢 302 室
```

不要简写、不要改顺序(先省市区再街道门牌)。如果户口迁过、身份证地址与现居地不同,**填身份证上的**——系统要的是证件信息,不是实际居住地。

- **不要加水印**、不要涂改
- 单个文件建议 200KB–1MB

## 七、常见填写错误(逐条核对)

| 易错点 | 正确做法 |
|---|---|
| 版本号填 `0.9.6` | 填 **V1.0** |
| 软件名称写"核核工具箱" | 写 **核核工具箱软件**(带"软件"二字) |
| 开发者填网名 `hehe` | 填**身份证姓名** |
| 开发方式选"合作开发" | 选**独立开发**(否则要交合作协议) |
| 证件地址填现住址 | 填**身份证上的地址** |
| 说明书没插截图 | ✅ 已插 5 张 |
| 源程序不足 60 页 | ✅ 恰好 60 页 |
| 上传 Word 而非 PDF | 必须 **PDF** |

## 八、填完之后

1. **提交后约 3–5 个工作日**收到受理通知书(邮件/短信)
2. 状态变为"受理中",开始实质审查
3. 普通流程 **30–60 个工作日**下证
4. 可在系统里随时查进度
5. 下证后是**电子证书**,可自行下载打印

**费用**:软件著作权登记**免费**(自 2017 年起取消收费)。只有"加急"需要付费(约 3000–8000 元,视时限)。

## 九、一个提醒

系统填写的所有信息会**印在证书上**。证书是公开可查的(登记号可在版权中心网站核查),所以:

- 姓名、证件号会显示在证书上(证件号部分隐藏)
- 联系地址、手机号**不会**印在证书上,只用于联系

如果你后续要用于公司资质、项目申报,证书上的著作权人姓名需要与实际申报主体一致——**这一点在填之前想清楚**。
