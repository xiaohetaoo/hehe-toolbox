## 六、开源与软著的关系

本项目已以 **MIT** 协议开源。这与软著申请**不冲突**：

- **软著**登记的是"谁是作者"这一事实
- **MIT** 是作者授予他人的使用许可

两者可以并存。但需注意：

1. 软著登记后，你仍是著作权人
2. MIT 已授权他人自由使用，**不能追溯收回**
3. 如果希望阻止商业使用，需要在申请后再调整许可证（但已发布的 MIT 版本无法收回）

**建议**：照常申请软著，开源协议保持不变。软著的价值在于：
- 官方登记证明（可作为技术成果证明）
- 某些资质申请、项目申报需要
- 侵权时的初步证据

## 七、办理流程概览

1. 在中国版权保护中心官网（`register.ccopyright.com.cn`）注册账号
2. 在线填写申请表（约 30 分钟）
3. 上传材料（说明书 PDF、源程序 PDF、身份证明）
4. 缴纳费用（目前软件著作权登记**免费**）
5. 等待审查（普通流程约 30–60 个工作日，可加急付费）
6. 获得《计算机软件著作权登记证书》
