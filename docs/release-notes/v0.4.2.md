# 核核工具箱 v0.4.2

这一版做的是**四件收尾工作**，没有新增工具，也没有改动任何功能的行为。用户能看到的只有一处：**英文界面下工具名和副标题终于是英文了**。

测试断言 **1448 → 1456**，`main.js` **4343 → 4344 行**，IPC 通道 **168 个全部常量化**（此前只迁了 8 个）。

## 英文界面下，工具卡终于是英文的

外壳文案（导航、首页、设置、状态栏）从 v0.3.x 起就是双语的，但 **102 个工具自己的名称和描述一直是纯中文**。英文用户打开首页，看到的是：

```
[icon] 图片压缩
    用质量滑杆和目标体积压缩图片
```

连「这是什么工具」都读不出来，比点进去发现正文是中文更早劝退。

现在每个工具都补了英文名与英文描述，**全部 102 个**，不是只翻译几个样板：

| 中文 | 英文 |
|---|---|
| 图片压缩 | Image Compress |
| 三栏对比 | Three-way Compare |
| 图片混淆 | Image Scramble |
| 目标体积压缩 | Target Size Compress |

实现方式与模块名沿用同一套约定：`registry.js` 新增 `toolName()` / `toolDesc()`，英文界面优先取 `nameEn` / `descEn`，**缺失时回退中文而不是空白**。首页卡片、搜索结果、标签页、最近使用、面包屑、工具页标题、高危工具锁定卡片，共 15 处渲染点全部改了。

顺带一件事：**搜索现在中英文都认**。以前 `search()` 只匹配中文名，英文用户输 `video` 什么也搜不到。现在两种语言的名字和描述一起参与评分，中文用户输英文也能找到工具。

## 168 个 IPC 通道全部换成常量

这是一个跑了三轮才敢动的地方。

`lib/channels.js` 早就存在，但只迁了 8 个通道（目录搬家、权限链接两个域），剩下 160 个散落成字符串字面量：

```js
handle('fs:stat', ...)          // 主进程
invoke('fs:stat', ...)          // 渲染层
```

打错一个字母的表现是运行时报 `No handler registered`，而**测试本身也是扫文本的**——两边都错成一样的就查不出来。

之所以一直没迁，真正的原因不是 160 处替换麻烦，而是**二十多个测试用 `src.indexOf("handle('通道名'")` 定位源码片段**。一迁，这些断言全部「找不到 handler」——不是断言失效，而是定位方式绑死在书写形式上。

所以先做两件事，再动迁移：

1. **把「怎么找到那段代码」抽成公共设施**（`scripts/lib/seg-from-handler.js`）。它按通道名反查常量路径，字面量和 `CH.FS.STAT` 两种写法都认。断言本身一条没删——之前坚持不批量改写源码断言，是因为那些断言各有语义；但「怎么定位」不是语义，是可以统一的。
2. **分批替换 + 每批跑测试**：主进程 4 个文件 160 处 → 渲染层 43 个文件 410 处（`invoke` 398 + 辅助窗口 7 + `api.js` 5）→ 修被绑定写法打红的测试。

结果：主进程 `handle` 字面量 **0 处**，渲染层表内通道字面量 **0 处**，168/168 全部常量化。独立核验脚本（不看测试，直接扫源码）通过。

顺带修掉一个真实的隐患：`win:ruler:close` / `win:ruler:move` 是双冒号，违反「域:动作」的格式约定，已改为 `win:ruler-close` / `win:ruler-move`。辅助窗口的 HTML 也补上了 `channels.js`（并加了断言保证它排在 DOM 逻辑之前，否则取 `window.Channels` 会是 `undefined`）。

## 最后两处键盘死角

v0.4.1 把工具页内的次级交互补到只剩 1 处，这一版清掉了：剪贴板历史里「点击图片 = 把这张图写回剪贴板」是图片条目**唯一**的操作入口，纯键盘用户之前能看见历史图片却一张都复用不了。

## 磁盘占用

`dist/win-unpacked/` 里那个 98MB 的 `app.asar` 一直被文件监视进程锁着删不掉。这一版把内容截断释放了空间（**70MB → 0**），目录本身仍在（空文件句柄未释放），DSH 重启后可删。新流程不再产生该目录。

## 主动放弃的（写进决策记录，防止后人重做）

- **420 条源码断言全量改写**：两次筛选尝试都是误判为主，判据不可操作。见 `docs/decisions/source-assertions-not-bulk-rewritten.md`。这一版只统一了「定位方式」，没有动断言语义。
- **合并 UI 测试的 Electron 启动**：实测只省 38 秒，代价是 21 个测试捆成一个进程，某个探针崩了后面全不执行。
