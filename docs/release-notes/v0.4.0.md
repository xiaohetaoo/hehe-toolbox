# 核核工具箱 v0.4.0

这一轮**终于是用户可见的变化**：修掉了几处视觉不一致。功能没有增减，但界面里那些「看着别扭」的地方没有了。

起因是一张截图：密码生成器的「长度 / 数量」输入框里，那对上下箭头和整个界面不是一套东西。

## 那对箭头不是我们的样式

`<input type="number">` 右侧的两个三角是 **Chromium 用系统控件画的**。它不吃 `border` / `border-radius` / `background`，在深色主题下就是浅灰底加两个深色三角，贴着 `#333336` 的输入框，像贴上去的补丁。

更麻烦的是：**它只在悬停或聚焦时出现**。平常看一切正常，鼠标一碰才露馅，所以跑截图巡检也发现不了。

修法是两层：

- `html[data-theme='dark'] { color-scheme: dark }`，让浏览器自己画的那部分（数字箭头、日历图标、下拉展开面板、滚动条）跟着主题走
- `appearance: textfield` 去掉箭头本身，再补上右侧内边距

**没有**去"美化"那两个三角。它们是 8px 见方的系统位图，没有稳妥的重绘方式。`min` / `max` / `step` 全部保留 —— 键盘 ↑↓、输入校验、滚轮都照常工作，去掉的只是那对图形。

顺带统一了同类控件：

| 控件 | 之前 | 现在 |
|---|---|---|
| 滑块 `range` | 系统蓝，9 套配色都不跟随 | 跟随主色 |
| 日期 / 时间框 | 日历图标深色底上几乎看不见 | 跟随主题 |
| 下拉展开面板 | 深色主题下弹出白底列表 | 跟随主题 |

## 「➕ 添加」上有两个加号

快捷启动的添加按钮，代码是：

```js
btn('➕ 添加', 'btn-primary', add, 'plus')
```

第 1 个参数给了 emoji 加号，第 4 个参数给了 `plus` 图标名 —— `btn()` 把两个都渲染了。放大看就是 `＋` 和 `➕` 并排。

这个 bug 藏得住，是因为两个加号长得像，正常缩放几乎看不出。

## 顺着这条线扫全站，发现 122 处

项目有一套统一的线性 SVG 图标库（89 个，24×24、stroke 2），但按钮文案里混进了 emoji 当图标。emoji 的字重、基线、颜色都不受控，深色主题下还会被系统换成彩色字形，和整套线条图标完全不是一套视觉。

统一改为 `btn()` 第 4 参的 SVG 图标：

| | 之前 | 现在 |
|---|---|---|
| 按钮里的 emoji | 91 | **0** |
| SVG 图标按钮 | 305 | **396** |
| 图书型 emoji（字体无法控制） | 15 | **7** |

剩下 7 处都是刻意保留的：toast 里的闹钟、Markdown 预览示例里的 ✅、以及一处为了让旧配置继续匹配的兼容正则。

## 一个必须一起修的连带缺陷

`btn()` 原本把文本作为**裸文本节点**塞进按钮。于是需要换文案的地方只能这么写：

```js
swapBtn.textContent = '⇄ 编码模式';   // 清掉整个子节点列表，连 svg 一起干掉
```

文本编解码那 5 个「编码 / 解码」切换按钮，初始有图标，**点一下就永久变成纯文字**。

改成包一层 `.btn-label` 后，只改这一层就能保住图标。实机逐个点击验证：

| 页面 | 点击前 | 点击后 |
|---|---|---|
| Base64 | svg=1「解码模式」 | svg=1「编码模式」 |
| URL 编解码 | svg=1「解码」 | svg=1「编码」 |
| Unicode 转换 | svg=1「解码」 | svg=1「编码」 |
| HTML 实体 | svg=1「还原」 | svg=1「转义」 |
| Hex / ASCII | svg=1「解码」 | svg=1「编码」 |

## 顺带

- 硬件信息页的卡片标题（处理器 / 内存 / 显卡 / 硬盘 …）改用图标位，不再往标题文字里塞 emoji
- 系统快捷操作（锁屏 / 睡眠 / 休眠 / 重启 / 关机）的按钮改用图标，且关机换成 `power` 图标、休眠与睡眠用 `moon` 区分
- 录屏页的麦克风 / 摄像头选项去掉了名字前的 emoji，但保留了对**旧配置里带 emoji 前缀**的兼容匹配 —— 否则升级后已保存的画中画设置会失效
