# v0.8.9 —— 开发环境

本版新增「开发环境」工具：把常用运行时做成**可删除、可回滚**的便携环境，安装时默认接入当前用户环境。

## 一、新增：开发环境（开发调试）

- **四个首批运行时**（版本、下载地址、SHA-256 全部入库固定，可离线复现）：
  - Node.js 22.23.5（npmmirror 镜像，npm 自带）
  - Java Temurin JDK 21.0.13+9（Adoptium 官方构建）
  - MinGW-w64 GCC 16.2.0（winlibs UCRT；**不是 MSVC**）
  - Python 3.12.16（python-build-standalone 便携完整版，**含 pip**）
- **下载 → SHA-256 校验 → 解压 → 落盘**：装到 `%APPDATA%\核核工具箱\envs\<id>\<version>`，删目录即净；zip 拒绝路径穿越，7z/tar 靠入库哈希兜底；落盘与回滚都走跨卷安全的 moveFile。
- **默认加入当前用户环境**：前置用户 PATH（Java 另设 JAVA_HOME），安装前二次确认；同时保留「仅本工具箱使用」选项。
- **已有版本检测**：`py -0p` / `where` / `java -version` / `gcc --version`，界面列出本机版本与路径，并明确警告「加入后新终端会优先使用工具箱版本」。
- **只改 HKCU**：系统 PATH 永不碰，不用 setx（1024 字符截断事故）；写入前备份，支持单条移除与「撤销全部环境修改」，撤销后 PATH 逐字还原（含重复项与尾分号）。
- **官方安装器入口**：Node MSI / Temurin MSI / MSVC Build Tools / Python 官方安装器——需要系统级或注册表登记时走厂商安装程序。
- **打开带环境的终端**：注入 PATH/JAVA_HOME 启动 cmd，不改系统；下载支持进度与停止。

## 二、安全与边界（如实说明）

- 便携 Python **不会被 `py` 启动器 / PEP 514 注册表识别**；需要"所有软件自动认"请用官方安装器。
- MSVC Build Tools 不提供下载安装（体积大、需管理员），只给官方入口。
- 版本是入库固定的，暂无"检查更新"；每个运行时只保留一个版本，升级会替换并留 `.old-*` 备份。
- 环境变量只对新进程生效（已广播 WM_SETTINGCHANGE；极端情况仍需重新登录）。

## 三、质量

- 新增 5 个测试文件（目录契约 / PATH 纯函数 / 检测解析 / 接线 / 应用-撤销状态机），全项目 204 脚本 / 2251 条断言全部通过。
- 真机验证：安装 Node → `node -v` 通过 → 撤销后用户 PATH 与安装前逐字一致 → 删除后目录消失。
- 工具总数 110 → **111**；IPC 常量 188 → **195**。
