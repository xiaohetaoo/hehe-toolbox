# v0.8.0-1 —— 文件安全与稳定性修复

本版本合并两轮代码审查修复，重点保护本地文件、收紧 Electron 页面权限，并修复下载、解压、更新和录屏行为。

## 文件保护

- 目录搬家逐文件检查完整内容哈希，并保留源目录备份供人工核对和清理，避免复制验证后的新写入被自动删除。
- ZIP/7z 解压拒绝目标目录中的危险链接，写入失败只清理本次创建的文件；7z 增加解压前清单预检、解压过程中实际输出限额检查及提交前复核。
- adm-zip 升级至 0.6.1，修复伪造零声明大小绕过解压限制的问题。
- 新加密文件使用 AES-256-GCM 认证格式 `HEHEENC2`，拒绝篡改内容；旧版 CBC 文件仍可解密，并提示其缺少完整性认证。旧版应用不能解密新格式，详见 [加密格式](../encryption-format.md)。

## 权限与稳定性

- 拦截页面发起的导航，IPC 只接受应用页面的主框架；文件解锁结束进程时遵守能力开关。
- 下载续传校验资源版本和响应范围，资源换版后从头下载，避免拼接不同版本的数据。
- 更新包使用主进程保存的资产信息核对大小、PE 头和可用的发布摘要；替换前后复查摘要。页面不能改写更新缓存。
- 录屏会话绑定发起窗口，启动、暂停、恢复和停止互斥，避免第二次启动覆盖暂停会话。
- 视频静音保留视频流；JSON 排序保留 `__proto__` 等字段；非递归权限修复不再向子项授予继承权限。
- 清理一条多余的 ESLint 屏蔽注释。

## 版本与验证

版本号按指定使用 `0.8.0-1`，版本检查兼容数字修订后缀；按 SemVer，它属于 `0.8.0` 的预发布版本。本次只提交 PR，不创建 Release 或版本标签。

两轮修复的验证使用单元测试、隐藏 Electron 窗口、临时普通/加密归档及合成视频。真实权限修改、结束用户进程、录屏设备采集和更新程序替换仅通过模拟依赖或生成脚本检查。详细验证边界见 [第二轮修复记录](../review-round2-fixes.md)。
