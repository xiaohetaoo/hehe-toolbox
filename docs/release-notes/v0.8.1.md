这一版来自一轮**约 10 小时的代码审查 + 真机交互走查**（覆盖全部 103 个工具、6 个设置分区、深浅色 9 种配色组合）。修了 3 个真缺陷，并按可读性给标签栏做了一处观感优化。

## 一、标签栏开十几个之后「认不出是哪个工具」（主问题）

### 现象

打开 13 个工具后，标签栏每个标签只剩**图标 + 省略号**，一个汉字也放不下。用户必须把鼠标逐个悬停、看 `title` 提示才能确认是哪个工具 —— 比直接切窗口还慢。

CDP 实测：13 个标签时每个 `.tab-label` 的计算宽度是 **0 ~ 6px**。

### 根因：关闭按钮「藏起来」却仍占位

```css
.tab .tab-close { width: 14px; visibility: hidden; }
```

`visibility: hidden` **不参与绘制，但仍然参与布局**。所以每个未悬停的标签都白占 **14px 宽 + 4px 的 gap**，13 个标签合计浪费约 **230px**。挤压段里文字空间正是被它吃光的（实测一个 52px 的标签，label 只剩 0px）。

### 修法（三处配合）

| 改动 | 作用 |
|---|---|
| `.tab-close` 改用 `display: none` | 真正从布局摘除，13 个标签立刻让出 ~230px |
| `min-width: 0`（无限压缩）→ `min-width: 44px` | 压到「图标 + 1~2 个字」就停，剩余转入横向滚动 |
| 标签左右两侧 18px 渐隐（`.overflow-left` / `.overflow-right`） | 滚动条全局隐藏，靠渐隐提示「另一侧还有标签」 |
| `.tab` 内边距 `12px` → `clamp(3px, 0.9vw, 10px)`、`gap: 2px` → `1px` | 少标签时观感不变，多标签时白赚约 100px 文字空间 |

键盘用户不受影响：`:focus-within` 时关闭按钮同样出现。

### 实测效果

| | 修复前 | 修复后 |
|---|---|---|
| 13 个标签的文字宽度 | 0 ~ 6px（全是图标） | **12 ~ 30px**（图标 + 1~3 个字） |
| 溢出时的滚动提示 | **无**（滚动条隐藏） | 两侧渐隐 + 方向类随滚动位置更新 |

## 二、独立窗口里「选择文件」对话框挂错父窗口

`dialog:open` / `dialog:save` 两条通道写死 `dialog.showOpenDialog(win, …)`，父窗口恒为主窗。

把标签拖成独立窗口后，在该窗口点「选择文件」：

- 对话框不在发起它的窗口居中，看起来像「点了没反应」；
- 不是该窗口的**模态**子窗口，用户还能继续点独立窗，容易连点出好几个对话框。

这与 v0.7.1 修过的「最小化/最大化/关闭按发起者路由」是同一类问题 —— 当时漏了 dialog。

修法：改用已有的 `senderWindow()`（按 ALS 上下文取发起窗口，托盘/定时这类无调用者的路径退回主窗）。渲染进程侧 **39 个调用点**全部经由这两条通道，一处修好全部生效。

## 三、科学计算器的千位分隔实际不可用

`lib/expr-eval.js` 的注释明确写着「`_` 允许用户写 `1_000` 这类分隔」，但实现只在 **token 边界**跳过 `_`。数字内部的 `_` 会把 `1_000` 切成 `1` 和 `000` 两个相邻 token，最终报「表达式尾部有多余内容」。

**注释承诺与实际行为相反**，属于典型「文档修了、代码没修」。

修法：把 `_` 收进数字扫描（`/[0-9._]/`），先剥掉再校验；报错信息仍用原始写法（`1_00_0.` 这种会原样告诉用户错在哪）。

实测：`1_000+1` 从报错变成 **= 1001**。

## 四、活跃标签滚入可视区

标签溢出转入横向滚动后，从搜索打开一个工具：界面已经切过去了，标签栏却看不到它，只有右缘的渐隐暗示「右边还有标签」。

补上 `scrollIntoView({ block: 'nearest', inline: 'nearest' })`：

- 已经可见时是 **no-op**，不会在每次重排/普通重绘时跳动；
- 不可见时滚到刚好贴边的位置，不做居中（居中反而让人找不到参照）。

实测 20 个标签时 `scrollLeft = 138`，活跃标签正确入镜。

## 七、已知限制

- **独立窗口的对话框归属**无法自动化验证（需要真实弹出原生对话框）。本次锁的是源码事实（父窗口参数 + 无写死），建议手工复核一次：拖一个标签成独立窗，点「选择文件」。
