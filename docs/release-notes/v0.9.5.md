# v0.9.5 —— 取消链路真正接通 + 批量任务生命周期收口

本版修的是 v0.9.4 留下的**一处真实错误**，以及它连带暴露的一类问题：
「代码看起来对、实际不生效」的死代码。

## 一、最关键：v0.9.4 的退出码检查是死代码

v0.9.4 为了修「定时关机假成功」，把 `runCmd` 改成按退出码判定，并在
`sys-tools.js` 里加了 `if (code !== 0) { 不 arm }`。**但这条检查从来没生效过**：

- `EXEC.RUN` handler 的两条 `runCmd` 路径都没传 `allowNonZero` → 非零退出直接 reject；
- 而 `lib/errors.js` 只透传**字符串** code（`PERMISSION` 等），数字退出码丢失。

结果是渲染层永远拿不到 `1116`（"没有正在进行的关机"）这类真实原因，
只能看到一整条 `Command failed: cmd.exe /c shutdown /a`。
「排期被拒」与「本来就没有计划」在界面上无法区分。

**修复**：`EXEC.RUN` 从载荷读 `allowNonZero` 并透传给两条 `runCmd` 路径；
定时卡两处 `shutdown` 调用显式声明它。

## 二、连带修掉 14 处同类死代码

v0.9.4 改 `runCmd` 默认语义后，仓里所有「调用后 `if (r.code !== 0) throw`」
的地方都成了死代码 —— 用户只能看到整条命令行，看不到程序自己说的话。

已逐一补 `allowNonZero: true`，把判成败交回**已经写好的分支**：

| 位置 | 数量 |
|---|---|
| `main.js`（7z 解压/读目录/列目录） | 3 |
| `ipc/env-manager.js`（解压 ×3、读/写用户变量、safeCmd） | 6 |
| `ipc/media-ffmpeg.js` | 4 |
| `ipc/dir-acl-links.js` | 1 |

## 三、定时取消按类型分流（原来必现假失败）

原实现只要 `mode` 非空就 `shutdown /a`，并**无条件清空整张一次性定时列表**。
三个必现问题：

1. **睡眠/锁屏点取消必报「取消失败」**：它们根本没有系统关机计划，
   `shutdown /a` 必然以 1116 退出 → 被记成失败。而主进程里的定时**其实已经撤掉了**。
2. **取消「提醒」会误删所有睡眠/锁屏定时**（提醒与它们无关），还多跑一次 `shutdown /a`。
3. **取消会清空别人的定时**：只该撤本页建的那条。

现在：

- **关机/重启** → `shutdown /a`；`0` = 已中止，`1116` = 本来就没有计划，**都算成功**；
- **睡眠/锁屏** → 只撤本页那条（新增 `onceId`）；`shutdown /a` 仅作兜底，失败只作附注；
- **提醒** → 零 IPC，直接清状态；
- 门禁拦截（`CAP_DENIED`）在非关机模式下不计失败（本应用根本没排过计划）。

## 四、取消失败后倒计时会静帧

`clearInterval` 之后不重挂，界面会停在红色的「关机」两个字上一动不动，
看起来像卡死。现在失败路径用 `arm()` 重挂展示用 interval（`fire` 是空函数）。

## 五、排期期间切页会留下无人清理的 interval

确认框 / `EXEC.RUN` / `ONCE_ADD` 三个 await 期间用户可能切走。返回后仍会
`arm()`，而 cleanup 早已跑过 → interval 永远没人清。

新增 `pageShown`（cleanup 置 false、onEnter 置 true）：已离开只记
`mode/targetTs/onceId`，不动界面；`CAP_DENIED` 的二级确认框也不会在离开后弹。

## 六、批量任务生命周期（16 处）

| 页面 | 修的问题 |
|---|---|
| `text-tools` TTS | 停止在 `tts:speak` 返回前无效；cleanup 只 kill 不复位 → 复用回来按钮永久灰 |
| `launch` 命令收藏 | 无重入守卫（连点起两个进程）；`EXEC.STREAM` 期间切页 → 孤儿进程；输出无上限 |
| `target-size` | 切页不置 `canceled`：整批图片继续落盘；复用回来 picker 锁死 |
| `img-batch` / `img-watermark` / `batch-ocr` / `img-dedup` | 四个批量页无停止按钮、无 cleanup；停止后仍报「完成」 |
| `img-scramble` | 只有 token 无停止按钮（处理几百张时无法中途停） |
| `file-tools` 全局搜索 | 全盘快扫没有停止入口 |
| `audio-cut` / `video-frames` / `chain` / `sys-tools` 磁盘分析 | 阻塞式长任务无 per-run token |
| `office` PDF 转图片 / 办公转换 | 同上 |
| `pdf-plus` 水印、提取文字、瘦身 / `pdf-pages` 保存 | await 窗口后的界面副作用会落到新页面 |
| 四个媒体页的「取消」文案 | 用户点取消却显示「已离开页面」；行上仍挂「压制中」 |
