chore: 补齐 dist 到 0.9.4 + 固化「每版补产物」流程

新增 scripts/fetch-dist.js（npm run dist:fetch <tag>）
  · 从 GitHub Release 拉全部资产到 dist/，SHA256 逐字节对 API digest 校验
  · 幂等：已存在且哈希一致时跳过，不重复下载
  · 流式哈希（不把 150MB 文件读进内存）
  · 自动删除旧版本产物
  · 60 秒无数据即中止（上次 fetch 流挂死的教训）

图片压缩离开停写、onEnter 过期清状态、局域网扫描复位。
